# Devanshu Raut Portfolio

Dark-first developer portfolio for Devanshu Raut, built with the Next.js App Router, Tailwind CSS v4, GSAP, and a gated Three.js hero scene.

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

```bash
npm run lint
npm run build
npm run start
```

## Environment Variables

No environment variables are required.

## Deployment

Deploy on Vercel with the default Next.js preset.

1. Import the repository into Vercel.
2. Keep the build command as `npm run build`.
3. Keep the output managed by Next.js.
4. Deploy.

The static CV remains available at `/cv.html` from `public/cv.html`.
